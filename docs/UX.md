# MARAN UI/UX Specification

## Navigation
Home · Missions · MARAN · Workforce · More

## Home
- MARAN identity and connection state
- Large voice orb + universal command composer
- Input: voice, text, camera, file, link
- Active missions and approvals
- Quick outcomes: Research, Leads, Marketing, Accounts, Documents, Build

## Voice Mode
States: Listening → Understanding → Planning → Working → Verifying → Done.
Supports interruption, correction, pause, cancel, and spoken confirmation.

## Mission Control
Each mission displays objective, plan, assigned agents, live progress, sources/evidence, artifacts, approvals, model/provider, usage, errors, retries, and final result.

## Workforce
Chief MARAN, persistent specialists, temporary agents. Agent details expose purpose, current task, skills, tools, model, permissions and activity.

## Approvals
Actions are Automatic / Ask me / Never allow. Consequential external actions require explicit approval according to policy.

## Verification
Results can be Verified, Partially verified, Conflicting, or Unable to verify, with evidence.

## Connections
Provider accounts and business integrations are permission-scoped. Secrets are never displayed after storage.

## Accessibility
Large touch targets, screen-reader semantics, high contrast, reduced motion, Tamil/English UI, and text alternatives for status color.
