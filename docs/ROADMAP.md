# Roadmap

## M0 — Foundation
Repository, contracts, UX, architecture, security model, CI.

## M1 — Usable Android shell
Compose design system, Home, Missions, Voice, Workforce, More, local demo mission engine.

## M2 — Orchestrator
Mission API, planner, agent registry, state machine, verifier, approvals, audit log.

## M3 — Model Router
Multiple configured providers, health/quota awareness, fallback, context handoff, budgets.

## M4 — Voice
Push-to-talk first; Tamil/English STT/TTS. Wake-word mode only through Android-supported foreground/assistant mechanisms with visible privacy state.

## M5 — Worker pack
Research, Tour Leads, SEO, Social, Documents, Accounting assistance, Coding/OpenCode.

## M6 — Integrations
GitHub and user-authorized email/calendar/storage/business integrations.

## M7 — Automation
Schedules, condition watches, notifications, resumable jobs.

## M8 — Production hardening
Threat model, encrypted secrets, backups, telemetry controls, accessibility, load/failure tests, signed release pipeline.
